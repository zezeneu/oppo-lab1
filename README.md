# Учебные занятия: дата, время, имя преподавателя

Строка ввода: `гггг.мм.дд чч:мм "Имя преподавателя"`, например
`2024.03.11 14:30 "Иванов И.И."`.

Требуется Visual Studio 2022 (стандарт C++20: нужен `std::chrono::year_month_day`).
Разбор строки — одно регулярное выражение `std::regex`; существование даты
(30 февраля, 31 апреля, 29 февраля не в високосный год) проверяет
`std::chrono::year_month_day::ok()`.

## Как открыть и запустить
Дважды щёлкните `Lessons.sln`, конфигурация **Debug**, платформа **x64**, затем **Ctrl+F5**.

## Ввод данных
Занятия читаются из текстового файла, а не из консоли. По умолчанию это `lessons.txt`
в папке проекта `Lessons` (рядом с `Lessons.vcxproj`; пример файла лежит там же).
Другой файл можно указать аргументом: Свойства проекта → Отладка → Аргументы команды
(например, `C:\data\lessons.txt`). Файл сохраняйте в кодировке **Windows-1251** (ANSI),
чтобы русские буквы правильно отображались в консоли.

Формат строки: `гггг.мм.дд чч:мм "Имя преподавателя"`. Месяц, день, часы и минуты можно
писать с одной или двумя цифрами (`2024.3.5 9:5 "Иванов"`). Регулярное выражение:
`[0-9]{4}\.[0-9]{1,2}\.[0-9]{1,2}` (дата), `[0-9]{1,2}:[0-9]{1,2}` (время) и имя в кавычках.
Пустые строки в файле пропускаются, чтение идёт до конца файла. Неверные строки
пропускаются с сообщением «Строка N пропущена: …».
Имя преподавателя для фильтра вводится с клавиатуры.

Работа 2: программа разбита на модули (`date_time`, `lesson`, `lesson_io`,
`lesson_sorting`, `lesson_filtering`, `console`). Вводятся несколько занятий,
затем они выводятся в порядке ввода, по возрастанию времени и по имени преподавателя.
